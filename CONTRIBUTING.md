# Contributing

This is a community reference project without a support SLA. Focused bug fixes,
tests, security improvements, and documentation updates are welcome.

1. Open an issue before large architectural changes.
2. Create a branch from `main` and add tests for behavior changes.
3. Run `make test`, `make lint`, and `make terraform-check`.
4. Never include datasource exports, TDS/TDSX files, credentials, account IDs,
   internal schemas, or production logs.
5. Submit a pull request using the repository template.

By submitting a contribution, you agree that it is licensed under Apache-2.0.
